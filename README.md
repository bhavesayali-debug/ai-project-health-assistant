# AI Project Health Assistant

## Overview

The AI Project Health Assistant is a prototype exploring whether AI can help Project Managers understand overall project health by analyzing information distributed across multiple project sources.

Project Managers often need to review information from Jira, sprint updates, meeting notes, risk and issue registers, milestone plans, defect trackers, stakeholder communications, and other project sources before they can understand the true status of a project.

This project explores how that information can be consolidated and analyzed to help surface project-health concerns that require PM attention.

## The Problem

Project information is often fragmented across multiple systems and communication channels.

The Project Manager must manually review, correlate, and interpret this information to understand:

* Overall project health
* Risks and issues
* Blockers
* Dependencies
* Milestone impact
* Sprint progress
* Defects
* Action items
* Scope/change signals
* Stakeholder concerns

Important signals can sometimes be difficult to identify early when information is distributed, high-volume, inconsistent, or outdated.

## Prototype Goal

The initial prototype will explore a simple question:

**Can AI analyze project information from multiple sources and provide an evidence-based view of project health for a Project Manager?**

The initial experience will allow a PM to ask:

**"What is the current status of this project?"**

The assistant will analyze a synthetic project dataset and identify relevant project-health signals.
